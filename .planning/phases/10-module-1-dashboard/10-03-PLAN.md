# Plan 10-03: Level 1 Global Filters & Level 2 Clickable 3x3 Cards Grid

## Objective
Implement Level 1 (Global Context Filter Bar) and Level 2 (3×3 Clickable Domain Cards Grid) with zero redundant navigation buttons and seamless reactive selection state.

## Execution Skills
- `ui-styling`
- `impeccable`
- `vercel-react-best-practices`

## Detailed Tasks
1. Create `src/components/dashboard/dashboard-filter-bar.tsx`:
   - Sticky top bar with quick filter dropdowns:
     - Term / Mandate: `26.1`, `26.2`, `Custom Date Range`, `Peak: Winter / Summer`
     - Product: `All ICX`, `iGV`, `iGTa`, `iGTe`
     - Rabat Organizational Engine: `All Engines`, `External Engine (BD, Sales, Partner Branding)`, `Internal Engine (Ops, IR, Quality, Visa/Logistics)`
     - Team / Owner: `All Roles`, `LCVP`, `Middle Manager (MM) / Team Leader (TL)`, or individual `Team Member (TM)`
   - Clear filters action and active filter pills.
2. Create `src/components/dashboard/domain-kpi-card.tsx`:
   - Interactive card container without any `"Go to Page"` CTA buttons.
   - Selected card state with active ring (`ring-2 ring-aiesec-blue border-transparent bg-blue-50/20 dark:bg-blue-950/30`).
   - Domain Title & Health Badge (`Green: On Track`, `Amber: At Risk`, `Red: SLA Breach`).
   - Primary MoS in prominent typography (Target vs. Actual + % Attainment).
   - 3 Headline KPIs with WoW delta badges (`▲ +12%` / `▼ -4%`).
   - Integrated Micro-Visual preview.
   - Click trigger invoking `onSelect(cardId)`.
3. Create `src/components/dashboard/domain-cards-grid.tsx`:
   - Responsive 3×3 grid rendering all 9 domain cards with clean loading & empty states.
