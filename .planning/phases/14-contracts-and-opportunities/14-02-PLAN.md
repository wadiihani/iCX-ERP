## Task Specification

### 1. Problem
Generic opportunity forms show irrelevant fields across products and treat SDG alignment as a passive badge without connecting it to planned activities, target beneficiaries, or delivered output evidence.

### 2. AIESEC Process & Source Basis
- GV Hub Project Portfolio: links projects to SDGs, target groups, planned activities, intended outputs, and delivery evidence.
- AEPP 4.2.1.4: Post-approval changes to core benefits, fees, or job description are prohibited without mutual variation.
- APIP 5.2.3.1.8: Partly-remote exchanges require ICB audit forms and duration controls.

### 3. Current Implementation Confirmed in Code
- `src/components/opportunity/create-opportunity-modal.tsx` has basic fields.
- Product-specific validations and SDG activity templates are not fully enforced.

### 4. Desired Behaviour
1. **iGV Project Portfolio Engine**:
   - 16 Official Projects: *Heartbeat, Fingerprint, Global Classroom, Green Leaders, Youth 4 Impact, Raise Your Voice, Explorer, Happy Bus, Skill Up!, On The Map, Equify, Eco City, Aquatica, Rooted, Myself My World, Scale Up!*.
   - Each project maps to Primary SDG, Secondary SDG, Target Beneficiaries, Planned Activities (multi-select/text), and Intended Output Indicators.
   - Lock `oppSalary = 0` (`disabled`). Duration restricted to 6–8 weeks.
2. **iGTa Professional Rules**:
   - 6 functional fields: *Business Administration, Business Development, Marketing, Finance, IT, Engineering*.
   - Lock `oppEpFee = 0` (`disabled` per APIP 5.2.3.1.4). Mandatory full-time supervisor selection from `db.contacts`.
3. **iGTe Teacher Rules**:
   - Teaching deliverables, curriculum level, language/subject, minimum 9 weeks, and minimum salary 3,000 MAD.
   - Lock `oppEpFee = 0` (`disabled`).
4. **Partly-Remote & Duration Gates**:
   - If `PARTLY_REMOTE`: require `remoteWeeks <= totalWeeks * 0.5` and mandatory ICB Audit URL (`aies.ec/partlyremote-auditform`).
   - Slot start dates must be within 365 days of creation date.
5. **Post-Approval Benefit & Fee Locking**:
   - If Opportunity has `approvedCount >= 1`: lock salary, working hours, accommodation, and fee. Require signed addendum for changes.

### 5. Data Model & API Changes
- Extend `Opportunity`:
  - `sdgPrimary`: number, `sdgSecondary`: number[], `targetBeneficiaries`: string, `plannedActivities`: string[], `expectedOutputs`: string.
  - `supervisorContactId`: string, `teachingLevel`: string, `icbAuditUrl`: string.
  - `isBenefitsLocked`: boolean, `variationAddendumUrl`: string.

### 6. Permission & Privacy Impact
- Opportunity publishing restricted to Opportunity Managers and LCVPs.

### 7. Acceptance Tests
- `tests/opportunity-and-slots.test.ts` and `tests/professional-exchange-validation.test.ts`:
  - Enforces iGV salary=0 and 6-8 weeks duration.
  - Enforces iGTa/e epFee=0 and supervisor requirement.
  - Validates partly-remote ICB audit URL requirement.
  - Validates post-approval benefit locking.

### 8. Migration & Rollback Plan
- Non-destructive schema addition; existing records default to unlocked or standard values.

### 9. Completion Evidence
- Vitest suite passing with 100% coverage on product validation gates.
