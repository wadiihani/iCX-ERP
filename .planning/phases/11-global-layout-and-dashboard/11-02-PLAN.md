## Detailed Tasks
1. Enhance `src/components/dashboard/dashboard-filter-bar.tsx` and integrate into the global workspace context:
   - Provide standard interactive dropdown selectors:
     - `Term / Mandate`: `26.2` (Default), `26.1`, `Custom Date Range`
     - `Peak`: `All Peaks`, `Winter Peak`, `Summer Peak`
     - `Product`: `All ICX`, `iGV`, `iGTa`, `iGTe`

     - `Owner / Member`: `All Members`, or individual member filter from Rabat team roster.

2. Build `src/components/layout/data-settings-modal.tsx`:
   - Accessible via the `⚙️ Data & Settings` button at the bottom of the Left Sidebar.
   - Tabs / Actions:
     - **Export System JSON**: Full database dump of all normalized tables into an encrypted/standard JSON file.
     - **Export Current Table (CSV/MD)**: Formatted table export adhering to active filters.
     - **Import JSON/CSV Backup**: Validates incoming schema, runs conflict checks, and restores operational tables.
     - **Reset to Statutory Rabat Seed Data**: Safe confirmation dialog with two-step validation before resetting mock database state.
3. Wire toast feedback via Sonner for all import/export/reset actions.
