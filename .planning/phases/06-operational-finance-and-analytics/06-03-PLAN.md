# 06-03-PLAN: Command Center Home, Dense Operational Metrics & Funnel Analytics

## Objective
Implement role-specific Command Center analytics, dense operational views, the full EP conversion funnel (`APP → ACC → APD → RE → FI → CO`), SLA compliance monitoring with small-sample warnings, and complete Svelte 5 views.

## Proposed Changes
1. **Backend Analytics Module (`services/api/app/modules/analytics/`)**:
   - `schemas.py`: `FunnelMetrics`, `SLAComplianceReport`, `FinancialSummaryReport`, `DashboardOverview`.
   - `service.py`:
     - Aggregate funnel counts across all stages: `APP`, `ACC`, `APD`, `RE`, `FI`, `CO`.
     - Stage conversion percentages and average duration in hours/days.
     - Small-sample warning flag (`sample_warning: bool` when cohort size < 5).
     - SLA compliance tracking: Application-to-First-Contact (48h target), Application-to-Screening, Opportunity review (72h target).
     - Financial summary: Total invoiced, collected, outstanding overdue receivables.
   - `router.py`: REST endpoints at `/api/v1/analytics/overview`, `/api/v1/analytics/funnel`, `/api/v1/analytics/sla`.

2. **Frontend Views (`apps/web/`)**:
   - `apps/web/src/lib/api/finance.ts`: client for finance, legalities, and analytics endpoints.
   - `apps/web/src/routes/(app)/finance/+page.svelte`: Pricing calculator widget, payment obligations table, receipts logger, and financial approval queue modal.
   - `apps/web/src/routes/(app)/legalities/+page.svelte`: Risk register 5×5 matrix, IAC audit checklist, and legal document repository.
   - Update `apps/web/src/routes/(app)/dashboard/+page.svelte`: Full Command Center operational hub with real-time KPI metrics cards, EP conversion funnel with small-sample alerts, active alerts, and quick actions.

3. **Automated Verification**:
   - Pytest tests in `services/api/tests/test_analytics_dashboard.py` verifying metric aggregations and small-sample detection.
   - SvelteKit `npm run build` verification.
