# Plan 15-02: Live Date-Math SLA Countdowns & AEPP Exception / Break Modal

## Objective
Implement Section 5 (`CHG-27`, `CHG-28`) of `aiesec_icx_erp_vercel_audit_and_complete_changes_blueprint.md`: replace static hours/integers with live date-math SLA timers based on statutory timestamps, and build the comprehensive Exception/Break/Rejection modal enforcing AEPP feedback and Annex 2 replacement timers.

## Execution Skills
- `vercel-composition-patterns`
- `impeccable`
- `ask-sonner`

## Detailed Tasks
1. Implement Live Date-Math SLA Engine in `src/lib/sla/sla-engine.ts`:
   - Store real timestamps on EP:
     `appliedAt`, `firstContactedAt`, `acceptedAt`, `approvedAt`, `heVisaPackSentAt`, `epVisaAppliedAt`, `op14dConfirmedAt`, `accomm14dConfirmedAt`, `pickup3dGuideSentAt`, `realizedAt`, `finishedAt`, `completedAt`, `lastContactAt`.
   - Compute real-time countdown badges:
     - **14d Post-APD Visa & Expectation Pack SLA (`AEPP 4.4.3.1`)**: countdown from `approvedAt + 14d` until `heVisaPackSentAt`.
     - **7d/14d EP Visa Application SLA (`AEPP 4.4.2.1`)**: countdown from `heVisaPackSentAt` until `epVisaAppliedAt`.
     - **Rabat 14-Day Pre-Arrival OP & Bed Lock**: verifies OP and bed confirmation `>= 14 days before arrivalDate`.
     - **3-Day Pre-Arrival Written Pickup Guide (`Standard #6`)**: countdown to `arrivalDate - 3 days`.
     - **48h Unreachable EP Safety Heartbeat (`AEPP 4.5.4.11`)**: alert if `(now - lastContactAt) > 48h` during realization.
2. Build `src/components/ep/ep-exception-modal.tsx`:
   - Supports:
     - **`REJECTED`**: requires written feedback per AEPP 4.2.3.5. Asks *"Did EP meet 100% of posted EXPA criteria?"* — if Yes & rejected by OP without valid cause, auto-increments OP's `unjustifiedRejectionsCount` per AEPP 4.2.2.1.7.
     - **`WITHDRAWN`**: logs pre-APD withdrawal root cause for Dashboard Pareto chart.
     - **`APPROVAL_BROKEN` / `REALIZATION_BROKEN` / `REMOTE_BROKEN` / `FINISHED_EARLIER`**: validates break reason under AEPP 4.4–4.5 and auto-spawns a Quality Case with `14d APD` or `7d RE` replacement timer per Annex 2.
