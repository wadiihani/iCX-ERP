## Task Specification

### 1. Problem
Dashboard metrics sometimes display decorative counters or hardcoded conversion steps without a documented mathematical formula. Clicking a KPI does not consistently drill down to the exact filtered records, and CSV imports write blindly without a dry-run preview.

### 2. AIESEC Process & Source Basis
- AIESEC Hub Roadmap §5.1 & §9: KPI Dictionary establishing owner, formula, source tables, grain, exclusions, reporting window, target source, and data freshness.
- No hardcoded live metrics: Every KPI must be reconcilable to source records.
- CSV imports must validate in a dry-run with preview and duplicate warnings before writing.
- Disaster recovery backup/restore must be tested to ensure data continuity.

### 3. Current Implementation Confirmed in Code
- Dashboard has 9 summary cards and graphs.
- CSV/JSON export/import exists in Data Settings, but dry-run schema validation and complete drill-down reconciliation require standardization against the KPI dictionary.

### 4. Desired Behaviour
1. **KPI Dictionary Implementation**:
   - Create `src/lib/dashboard/kpi-dictionary.ts`:
     - Documents 14 core metrics: Lead-to-Meeting Conversion, Deal Win Rate, Stage Aging, Active Qualified Partners, Usable Slot Capacity, Confirmed IR Supply, EP Stage Conversion, Time to Match, Standard Fulfillment, Feedback Completion, Arrival Readiness, Collected vs. Expected Revenue, Overdue Task Rate, and Project Output Evidence.
     - Distinguishes `0`, `N/A`, `not configured`, `insufficient data`.
2. **100% Drill-Down Scorecards**:
   - Clicking any metric on the Dashboard opens an in-place filtered drawer/modal displaying the exact underlying records.
3. **Validated CSV Import with Dry-Run Preview**:
   - In Data Settings modal (`src/components/layout/data-settings-modal.tsx`):
     - Displays dry-run preview before committing: total rows parsed, valid rows, invalid rows with specific column errors, duplicate warnings, and summary of planned inserts/updates.
4. **Disaster Recovery Restore Drill**:
   - Automated test verifying full export-wipe-restore cycle with 100% data integrity and zero broken relations.

### 5. Data Model & API Changes
- Export `KPIDefinition` interface with `metricId`, `title`, `formula`, `sourceTable`, `grain`, `exclusions`, `freshness`.
- Add `validateCsvDryRun(csvString, targetEntity)` parser in `src/lib/crm/crm-import-service.ts`.

### 6. Permission & Privacy Impact
- Export and import actions require Admin or LCVP role authorization.

### 7. Acceptance Tests
- `tests/disaster-recovery-and-restore.test.ts` & `tests/command-dashboard.test.ts`:
  - Validates KPI formula outputs equal count of underlying records.
  - Validates CSV import dry-run rejects malformed rows and warns on duplicates.
  - Validates backup/restore round-trip with zero record loss.

### 8. Migration & Rollback Plan
- Non-destructive addition to dashboard and import engines.

### 9. Completion Evidence
- Vitest passing 100% on dashboard and disaster recovery test suites.
