# Plan 05-03: CXP Standards Engine (18 Standards), Evidence Vault, Completion Calculator & Svelte 5 Views

## Objective
Implement the 18 Exchange Standards fulfillment engine with 13 mandatory standards gates, 10 Partner Standards tracking, document evidence verification, deterministic completion readiness calculation (requiring 16/18+ standards and 100% of mandatory 13), and responsive Svelte 5 operations views (`/exchanges` and `/cxp`).

## Scope
1. **The 18 AIESEC Exchange Standards Framework**:
   - 16 Core + 2 Optional Standards:
     1. Personal Goal Setting (`MANDATORY`)
     2. Outgoing Preparation (`MANDATORY`)
     3. Expectation Setting (`MANDATORY`)
     4. Visa and Work Permit (`MANDATORY`)
     5. Arrival Pickup (`MANDATORY`)
     6. Departure Support
     7. Job Description (`MANDATORY`)
     8. Working Hours (`MANDATORY`)
     9. Duration (`MANDATORY`)
     10. Opportunity Provider / Line Manager (`MANDATORY`)
     11. Basic Living Conditions (`MANDATORY`)
     12. Compensation / Salary (`MANDATORY`)
     13. Health Insurance (`MANDATORY`)
     14. First Day of Work (`MANDATORY`)
     15. Alignment Space with OP
     16. Leadership Development (LDA)
     17. Incoming Preparation Seminar (IPS)
     18. Debrief with AIESEC
2. **Database Schema & Migrations**:
   - `exchange_standards_fulfillment` table: UUID, exchange_id, standard_number (1-18), standard_name, is_mandatory, is_fulfilled, fulfillment_date, verified_by, evidence_doc_url, verification_notes.
   - `partner_standards_evaluations` table: UUID, exchange_id, partner_id, standard_number (1-10), is_fulfilled, notes.
   - `exchange_completions` table: UUID, exchange_id, total_standards_fulfilled (0-18), mandatory_standards_fulfilled (0-13), is_eligible_for_completion, calculated_at, approved_by, completion_status (`PENDING`, `APPROVED`, `REJECTED`).
3. **Deterministic Completion Readiness Calculator**:
   - Pure code engine: an exchange is ONLY eligible for `COMPLETED` if:
     - `mandatory_standards_fulfilled == 13` (100% compliance on mandatory gates).
     - `total_standards_fulfilled >= 16` (overall threshold).
   - Invariant: AI agents CANNOT mark completion autonomously; completion requires verified calculations and explicit human approval sign-off.
4. **Svelte 5 Operations Views**:
   - `apps/web/src/routes/(app)/exchanges/+page.svelte`:
     - Operations dashboard with Pre-Arrival, Arrived, and Realized boards.
     - Modality checklist drawer.
     - Arrival pickups board & Accommodation occupancy tracker.
     - Incident case reporter.
   - `apps/web/src/routes/(app)/cxp/+page.svelte`:
     - 18 Exchange Standards interactive matrix with evidence upload and mandatory badges.
     - Completion readiness indicator and sign-off action.

## Dependencies
- Phase 5-01 & 5-02 backend services.

## Verification Criteria
- Automated pytest tests in `services/api/tests/test_cxp_standards.py`:
  - Enforces all 13 mandatory standards.
  - Reject completion when mandatory standard is missing even if total >= 16.
  - Approve completion only when criteria are deterministically satisfied.
- Frontend production build passes `npm --prefix apps/web run build`.
