# 07-02-PLAN: Knowledge Base & Policy RAG Assistant with Citation Grounding

## Objective
Implement the local policy knowledge repository, text chunking with metadata tagging, and the Policy RAG Assistant with strict source citation grounding and confidence tags.

## Proposed Changes
1. **Database Schema Additions**:
   - `knowledge_documents`: title, document_code, category (`GLOBAL_COMPENDIUM`, `ICX_SOP`, `LOCAL_MOROCCO_POLICY`, `EXCHANGE_STANDARDS`), version, effective_date, raw_text, file_url.
   - `knowledge_chunks`: document_id, chunk_index, content, section_heading, page_number, metadata_tags (JSON), token_count.

2. **Backend Engine (`services/api/app/modules/ai/knowledge/`)**:
   - `service.py`: Document ingestion, chunking, retrieval by keyword and semantic search, grounded prompt construction with strict citation enforcement rules.
   - Grounded Response Formatter: guarantees that every factual claim is backed by a bracketed citation (e.g. `[Source: Global Compendium 2026, Sec 4.2]`) and marked with an evidence tag (`[VERIFIED]`, `[OFFICIAL]`, or `[CONTEXTUAL]`). Speculative answers are explicitly blocked with a disclaimer.
   - `router.py`: REST endpoints at `/api/v1/ai/knowledge`.

3. **Automated Verification**:
   - Pytest tests in `services/api/tests/test_policy_rag.py` verifying document ingestion, chunk retrieval, and citation verification tags.
