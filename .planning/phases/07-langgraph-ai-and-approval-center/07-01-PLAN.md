# 07-01-PLAN: LangGraph Multi-Agent Architecture, Typed Tool Registry & Approval State Machine

## Objective
Establish the LangGraph multi-agent infrastructure, typed permission-checked tool registry, and the durable approval proposal state machine ensuring consequential AI mutations are strictly gated by human sign-off.

## Proposed Changes
1. **Database Schema (`database/migrations/007_ai_agents_and_approvals_schema.sql`)**:
   - `ai_agent_runs`: conversation id, agent name, user id, prompt, result, latency_ms, tokens_used.
   - `ai_agent_tool_calls`: run id, tool name, tool arguments (JSON), tool result (JSON), status (`SUCCESS`, `BLOCKED`, `ERROR`).
   - `approval_proposals`: proposal type (`STATUS_MUTATION`, `FEE_WAIVER`, `EMAIL_DISPATCH`, `EXCHANGE_COMPLETION`, `STANDARD_OVERRIDE`), target entity (e.g. Application, Obligation, Exchange), proposed payload (JSON), rationale, agent run id, status (`PENDING_HUMAN_REVIEW`, `APPROVED_EXECUTED`, `REJECTED`), reviewed by, reviewed at, rejection reason.

2. **Backend Engine (`services/api/app/modules/ai/`)**:
   - `tools/registry.py`: Typed tool definitions with Pydantic arguments (e.g. `get_application_profile`, `search_opportunities`, `get_partner_history`, `check_standards_fulfillment`, `draft_approval_proposal`). Strictly checks user RBAC permissions before invocation.
   - `graph/state.py`: LangGraph state definitions (`AgentState`).
   - `graph/supervisor.py`: Supervisor / routing graph dispatching to specialist subgraphs.
   - `service.py`: Agent execution runner, audit logger, and approval proposal creation.
   - `router.py`: REST endpoints `/api/v1/ai/chat` and `/api/v1/ai/runs`.

3. **Approvals Subsystem (`services/api/app/modules/approvals/`)**:
   - `service.py`: Proposal listing, approval execution (dispatches actual domain mutation upon human sign-off), and rejection.
   - `router.py`: REST endpoints `/api/v1/approvals/`.

4. **Automated Verification**:
   - Pytest tests in `services/api/tests/test_ai_agent_governance.py` testing tool execution, blocked unauthorized mutations, proposal creation, and approval execution.
